# Практики по анализу данных и проектированию

Учебный набор Jupyter Notebook по дисциплине, связанной с анализом данных,
моделированием и обработкой результатов экспериментов.

## Состав

Работы организованы по notebook-файлам `pr1.ipynb`–`pr16.ipynb` и сопровождаются
результатами визуализации.

## Запуск

```bash
python -m pip install jupyter pandas numpy matplotlib
python -m jupyter notebook
```

Открывайте notebook нужной практической работы и выполняйте ячейки сверху вниз.
Входные данные и результаты находятся рядом с соответствующей работой.

Репозиторий входит в учебный кластер портфолио.
