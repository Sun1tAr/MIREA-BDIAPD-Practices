# Слайд 1: Цель работы
### Цель практической работы
- Провести факторный анализ данных о пассажирах авиакомпании
- Оценить пригодность данных для факторного анализа
- Определить оптимальное количество факторов
- Интерпретировать полученные факторы
- Визуализировать результаты

### Используемые методы
- **Критерий Бартлетта** — проверка коррелированности переменных
- **KMO тест** — оценка адекватности выборки
- **Метод главных компонент (PCA)** — выделение факторов
- **График каменистой осыпи** — определение числа факторов

**Результат:**
